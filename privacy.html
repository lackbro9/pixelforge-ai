Privacy Policy

Last updated: August 2026.

File processing

Image Compressor, Image Resizer, Image Cropper, JPG to PNG, PNG to JPG, WebP Converter, Color Picker, Image Metadata Viewer and Image to Text (OCR) all process your file using your browser's own capabilities. Your file is not uploaded to any server operated by PixelForge AI, and we do not retain a copy of it.

Local storage

We store only your theme preference (light, dark or auto) in your browser's localStorage. This never leaves your device and contains no personal data.

Third-party resources

The Image to Text tool loads the open-source Tesseract.js library from a public CDN (jsdelivr) so it can run in your browser. Loading this script involves a standard network request to that CDN, subject to their own privacy practices; your image itself is not sent to the CDN or anywhere else.

Future AI tools

If AI-powered tools that require server-side processing are added later, this policy will be updated first to explain exactly what is sent, where, and why, before that tool is marked as available.

Contact

Questions about this policy can be sent through the contact page.
