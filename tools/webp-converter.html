Frequently asked questions

Why convert to WebP?

WebP typically produces smaller files than JPG or PNG at similar visual quality, which helps pages load faster.

What if my browser can't create WebP files?

Nearly all modern browsers support encoding WebP via the Canvas API. If yours does not, you'll see a clear error message instead of a broken download.
