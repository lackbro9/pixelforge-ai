Image Metadata Viewer

See an image's real dimensions, file size, type and available EXIF tags. Everything is read locally in your browser.

JPG, PNG or WebP · up to 25 MB

Your file is processed in your browser. It is never uploaded to a server.

Limitations

EXIF reading currently covers common tags (Make, Model, Orientation, DateTime) in JPEG files. PNG and WebP typically carry little to no EXIF data.
